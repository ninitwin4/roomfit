# roomfit

A mobile-friendly web app that matches renters to available rooms based on
their preferences and lifestyle — so you find a place that actually fits, not
just one that's available.

> Built during a 30-day build challenge. Work in progress.

---

## What it does

Finding a room usually means scrolling endless listings and guessing whether
you'll actually get along with the place and the people. roomfit flips that:
you tell it what matters to you — budget, location, lifestyle, the things that
make a shared home work — and it ranks available rooms by how well they fit.

## Core loop

1. **Set your preferences** — budget, location, and lifestyle basics.
2. **See ranked rooms** — available listings, sorted by compatibility.
3. **Understand the match** — see *why* each room ranked where it did.
